# About page + stats page + footer: 3 easy SEO wins

Standard practice, effect unproven: treat as a checklist and measure in Search Console.

## 1. About page
1. Opening sentence: what the company sells and who it helps, in one line ("X is a ... for ...").
2. "What we do" in plain words, then specifics with numbers (prices, sizes, counts, areas, years). No vague claims.
3. Name customer types (real customers or testimonials only with permission).
4. Real people: names, photo, role, links to LinkedIn/socials, contact email.
5. Any result claim needs the sample, dates and method beside it. Never invent a number; if you have no data, leave it out.
6. Link to the statistics page.

## 2. Statistics page (only if there is something to cite)
- 8-20 numbered stats, each linked to its original source (not a blog repeating it); no duplicates.
- Add your own measured findings with sample size, date range and method.
- Link it from the About page and from relevant service pages.
- Skip it entirely if you have no real data; a thin stats page is worse than none.

## 3. Footer
- 4-6 priority product/service/pricing/use-case links in one shared footer column, site-wide.
- Pricing (or "get a quote" / "book a call") one click from every page.

## Steps when run
1. Fetch the live pages (read-only).
2. Score each of the three against the lists above.
3. Draft replacement copy in the owner's voice and show it before anything is published.
4. List the missing facts to ask the owner for.
5. Never edit a live site without the owner's OK.
