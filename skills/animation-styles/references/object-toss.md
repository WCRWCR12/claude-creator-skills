# Object Toss family

Edit-led transitions built around a thrown or held object that anchors the frame.

All styles here are coded (Remotion or HTML + ffmpeg). Plain-English look first, specs after.

## Object Toss

**What it looks like:** Object tossed to the lens, black-bar band around it, card swaps inside the object while the scene whips behind

- **Palette:** #000000, #F2D41B, #FFF6B0, #FBFBFB, #E5122B, #B9B9B9
- **Type:** Scrambled-letter headlines (Inter ExtraBold, Anton), thin grotesque hook line, handwritten Caveat labels with curved arrows, red highlighter chips with white text.
- **Layout:** Black stage; footage window crops to a ~470 px band with one object fixed at exact screen centre; white grid-paper section for headlines; black tail with word-per-beat text.
- **Texture:** Flat colour; drop shadow on the object and cards only; motion blur only on whips.
- **Motion:** Toss-up grow, bar close to band, object bounce plus whip on each scene swap, screen-fill circle reveal, whip-off with curve line, asterisk spin-in, scramble type.
- **Best for:** Showcase reels where one product or prop carries the viewer through several scenes; how-I-made-this tutorials; any beat that needs a physical match-cut energy.
