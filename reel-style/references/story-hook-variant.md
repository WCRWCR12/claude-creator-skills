# Story-hook variant (same visual format, different script)

**Source:** studied from a public Instagram reel in the same tool-explainer family (instagram.com/reel/De3s5v3vIzE, Oct 2026): a "clean the ads and bloatware off your TV with Claude Code" explainer that drew roughly 75x the likes of the main reference, with the same format. Lessons below are restated, not quoted.

The format, pacing, captions and B-roll rules are identical to SKILL.md. What changes is topic choice and the script shape.

## Pacing
19 spoken lines in ~35-38 s = ~1.9-2.0 s per beat. Same density as the main reference.

## Beat map (shape)

| Beat | Time (approx) | Line type | Shot |
|------|---------------|-----------|------|
| 1-2 | 0:00-0:05 | Hook card holds; "Comment [WORD] to get [thing]" | Hook card, highlight bar on line 2, two thumbnails |
| 3-4 | 0:05-0:09 | Trend anchor ("people are now doing X") | Face, or a screen of the thing |
| 5-6 | 0:09-0:13 | "It's blowing up right now" + origin ("it started when someone...") | Social post screenshot, full frame |
| 7-10 | 0:13-0:21 | What it did, with specific numbers | Screen recordings / a number card |
| 11 | 0:21-0:23 | The analogy | Face |
| 12-13 | 0:23-0:27 | Proof ("a free repo with 16k stars") | Repo screenshot, then big number card |
| 14-16 | 0:27-0:33 | How to use it in one step, plus a bonus outcome | Tool screenshot, face, result screen |
| 17 | 0:33-0:35 | Scale ("works with 170+ models") | Face or compatibility screenshot |
| 18-19 | 0:35-0:39 | Reassurance ("you can undo it with one command") + CTA | Face + "WORD" in quotes |

## Script skeleton

1. Hook / promise: "Comment [WORD] to get [THING]. [What it does for you in one line]."
2. Trend anchor: "People are now [doing a relatable thing with AI]. And it's blowing up."
3. Origin story: "It started when [someone] did [specific thing]."
4. What it did, with numbers: "It [did X], [did Y] and [did Z]."
5. Analogy: "Think of it like [relatable metaphor]."
6. Proof point: "That turned into a [free repo / tool] with [N] stars."
7. How to use it: "You [paste one prompt / run one command]. It [does the thing]."
8. Bonus outcome: "Then it [extra result]. Or you can even [customise it]."
9. Scale: "It already works with [N] [devices / platforms]."
10. Reassurance: "And if you don't like it, you can [reverse it]. With [simple action]."
11. CTA: "[WORD]" on screen while the VO says "comment [WORD]".

## Lessons

1. **Topic selection is the real variable.** Same format, ~75x the result, because the topic was a mass-market pain (TV ads) instead of a developer niche. Pick topics everyone already feels.
2. **Trend-riding accelerates the hook.** "It's blowing up right now" piggybacks a moment that is already viral and adds urgency. Only say it when it's true.
3. **Origin story beats a capability list early.** "It started when..." plus specific details (counts, model numbers) is more credible and more shareable.
4. **Kill the objection before the CTA.** A one-line reassurance ("you can restore everything with one command") answers the doubt before the viewer has it.
5. **Comments dominate on keyword-CTA reels.** A ~24% comment-to-like ratio (vs a typical <5%) came from a memorable everyday CTA noun. Pick CTA words the audience already uses daily, not jargon.

## Which skeleton to use
- Topic has a genuine trending angle: this story-hook skeleton.
- Otherwise: the capability-list skeleton in SKILL.md.
Both land in the same visual format.
