# Writing talking-head reels

How to write a script for a talking-head reel BEFORE filming. The edit can only tighten what was said;
it cannot invent a hook. Distilled from studied reference reels plus standard short-form practice.
All example lines below are originals.

Before writing, pin the creator's **lanes**: the 2-4 recurring topics their audience follows them for
(e.g. "self-improvement framed as a game", "building a small business", "AI tools that save time").
Every script sits in one lane.

Read with: `GRAPHICS.md` (what can go on screen) and `RULES.md` (how it gets cut).

---

## 1. The non-negotiables

1. **The first sentence is the video.** It has to be understood with the sound off in under 2 seconds,
   and it has to make one specific promise or open one specific loop. Write it last, rewrite it ten times.
2. **Say the payoff early, deliver it late.** Name what they'll get in the first 5 s; hand it over at the end.
3. **One idea per reel.** If you need "and also", that's a second reel.
4. **Every line earns the next line.** If a sentence doesn't make them want the next one, cut it.
5. **Spoken, not written.** Short sentences. Contractions. Words the creator actually uses. Read it aloud;
   if they trip, rewrite it.
6. **Length: 30-60 s** (RULES.md rule 7). Roughly 140-160 spoken words per minute, so 75-150 words.
   A tutorial or list can run to 90 s only if the countdown or numbered steps make the length feel earned.
7. **Every line has a visual.** Mark what is on screen for each beat (graphic, B-roll, screen recording,
   or just the face with a punch-in). A line with no possible visual is usually filler.
8. **No fake claims.** Numbers must be real. If a tool or assistant is AI, never imply it is a human.

---

## 2. Hook formulas

Pick the formula from what is TRUE about the content. Never write a hook the body doesn't pay off.

| # | formula | shape | example (original) |
|---|---------|-------|--------------------------|
| 1 | **Easier than you think** | "It's never been easier to [result], and almost nobody's doing it." | "You can have a full-time assistant for less than your phone bill, and almost nobody's set one up." |
| 2 | **If you want X, do Y** | "If you want [result], you need to [counter-intuitive action]." | "If you want to stop procrastinating, stop treating your life like a to-do list and start treating it like a game." |
| 3 | **Call-out + stakes** | "If you're a [who] and you don't [know X], watch this." | "If you're building a business on your own and you haven't automated your admin yet, you're doing two jobs for free." |
| 4 | **Numbered promise** | "[N] [things] that [result] in [timeframe]." | "Three systems that run my day so I don't have to." |
| 5 | **Proof first** | Show the result, then "here's how." | "This is an AI booking a table while I'm in a meeting. Here's how it works." |
| 6 | **Contrarian** | "Stop [common advice]. It's why you're [bad outcome]." | "Stop setting goals. Set quests. Goals don't tell you what to do on a Tuesday." |
| 7 | **Identity / describe them** | Describe the viewer so precisely they feel seen. | "You've got ten tabs open, three half-built side projects and you still feel behind." |
| 8 | **Mistake / cost** | "The [mistake] that cost me [real cost]." | "The mistake that cost me six months on my first business: building before anyone asked for it." |
| 9 | **Before/after** | "[Before state] to [after state] in [time]. One change." | "From missing every deadline to never missing one, and I didn't get more disciplined." |
| 10 | **Question that stings** | A question the viewer can't answer comfortably. | "What level would your life be if you counted every day as XP?" |

Wording rules for the first line:
- Lead with the most concrete noun ("an AI assistant", "six months", "my calendar"), not "So today...".
- Under ~15 words. No greeting, no name, no "in this video".
- A number or a named thing beats an adjective.
- It must make sense as on-screen text alone (people watch muted). The title banner is usually the hook, shortened.

### Hook stacking
Don't stop at one hook. Stack three in the first ~10 seconds, flowing as one paragraph, BEFORE any value:
1. **Hook = pattern interrupt / call-out** ("if you're a [who] and you [don't know X], watch this"), then
2. **Super-hook, pain** ("twist the knife"): the specific cost of NOT watching ("if not, you'll keep
   [concrete bad outcome]"). It can be strong, but must be true for the viewer, not melodrama, then
3. **Super-hook, dream outcome**: the specific result if they do ("instead, you'll [concrete good outcome]"),
then a one-line bridge into the value ("here's how it works"). The seams must be invisible: no pause,
no "so anyway"; each hook flows into the next.
Halfway through, drop a **re-hook** (a second hook) before the main value or the hardest step, so the
middle doesn't sag: "But this next part is the bit nobody does."

Example stack (productivity lane):
> "If you run a business on your own and your admin isn't automated yet, watch this. If not, you'll keep
> answering emails at 11pm doing a job you could hand off. Set it up once and you wake up to your calendar
> sorted and every reminder already set. Here's how it works."

Example stack (life-as-a-game lane):
> "If you keep starting things and quitting by week two, this is for you. Otherwise next January you'll
> be writing the same resolutions again. Fix this and you'll actually see yourself level up, week by week.
> It starts with one change: stop setting goals, start earning XP."

### Progressive intrigue
For lists, open a loop that only closes at the end ("the last one is the one that actually changed
things") and order items from surface-level to deepest. People stay to reach the "ultimate" item.

## 3. Structure templates

Timings assume a ~45 s reel. Beats in **bold** are where a graphic event belongs (see GRAPHICS.md).

### A. Triple problem -> hook -> solution -> explain -> second hook -> solution -> CTA
| beat | time | what | example (life-as-a-game) |
|------|------|------|--------------------------|
| 1. Triple problem | 0-5 s | Three fast pains in one breath, rising | "You start the gym, you quit. You start the diet, you quit. You start the business, you quit." |
| 2. **Hook** | 5-8 s | Name the reframe/promise | "It's not discipline. You're playing the wrong game." |
| 3. Solution 1 | 8-15 s | The core idea in one line | "Turn your life into an actual game: XP for every rep, every page, every call." |
| 4. Explain | 15-28 s | How it works, one concrete example | "Ten XP for a workout. Fifty for a hard conversation. Hit a thousand and you level up." |
| 5. **Second hook** | 28-31 s | Re-hook before the bigger payoff | "But the bit that actually keeps you going is this." |
| 6. Solution 2 | 31-40 s | The deeper/second layer | "You can't lose XP. Miss a day and you just didn't earn any. Nothing to quit." |
| 7. **CTA** | 40-45 s | One ask | "Comment GAME and I'll send you the XP sheet." |

### B. Numbered list / listicle
Hook with result + number -> "it only works if..." (stakes) -> items 1..N, each = **one sentence that
names it + one sentence that explains it** -> items get deeper as they go -> honest caveat -> CTA.
Keep every item roughly the same length; a numbered `callout` or step label on screen for each.

### C. Tool/system demo
"It's never been easier to X" + proof clip in the first 5 s -> name the tool -> "here are the 3 steps" ->
step 1/2/3 with a screen recording on screen, the speaker pointing at it -> the money/time angle -> CTA keyword.

### D. Story -> lesson
Specific moment ("Tuesday, 11pm, three missed deadlines") -> what went wrong -> the turn -> the lesson in
one line -> how they can use it -> CTA.

### E. Proof -> how
Open on the result (a screen recording of the thing working, a number, a before/after) -> "here's how" ->
2-3 steps -> CTA.

## 4. CTA patterns

One CTA per reel. Last line, never cut (RULES.md rule 13). Leave the last ~1.5 s visually clean.

| pattern | use when | example |
|---------|----------|---------|
| **Comment KEYWORD for the thing** | you have a free resource (guide, template, prompt, sheet) | "Comment GUIDE and I'll send you the setup guide." |
| **Follow for part 2** | it's a series | "Follow, part two is how it handles the calendar." |
| **Save this** | tutorials, lists, checklists | "Save this so you've got it when you sit down to build." |
| **Send this to** | identity / relatable content | "Send this to the friend with five side projects." |
| **Question to comment** | opinion / contrarian | "What's your current level? Be honest." |

Keyword CTA rules:
- One short, all-caps word that matches the topic (GAME, GUIDE, QUEST, SYSTEM). Put it on screen as a
  big word card at the CTA.
- Only promise what exists. The resource must be ready before posting, and the creator must actually
  deliver it (by hand or with an automation they set up; no links in public replies).
- Repeat the keyword in the post caption's first line.

## 5. Pre-filming checklist

Before recording, check the script against this list:

- [ ] One idea. Can be said in one sentence.
- [ ] First line under 15 words, concrete, works muted, and the body pays it off.
- [ ] Hook stack: 2-3 angles in the first 10 s (who / pain / dream), or a proof shot.
- [ ] A re-hook before the main value or halfway.
- [ ] Every line has a visual noted (graphic type, B-roll `want`, screen recording, or face + zoom).
- [ ] 75-150 words (30-60 s). Read aloud with a timer.
- [ ] Numbers are real; claims about any tool are honest.
- [ ] One CTA; the resource exists if it's a keyword CTA.
- [ ] Title banner text written (the hook, 3-7 words) for the top of the first 3-6 s.
- [ ] Filming: phone at eye level, face in the middle third (keeps the `face_box` valid), light in front,
      quiet room. One take per line is fine (the cut keeps the last good take, RULES.md rule 5).
- [ ] Pause a beat between lines (clean cut points), start each line fresh, no "um so" run-ins.
- [ ] Any B-roll / screen recordings listed and captured (drop them in `edit/broll/`).
- [ ] No sound effects planned unless the creator wants them. Music optional, under the voice.

---

## 6. How to write a script on request ("help me write a script")

1. Ask (or infer) the lane, the one idea, the real proof/number, and the CTA resource.
2. Write 5 hook options from different formulas in section 2; recommend one.
3. Fill a template from section 3; mark each beat with its visual.
4. Give the title banner text and the CTA keyword.
5. Run the checklist; hand the script over as short lines that can be read off a phone.
6. After filming, the edit runs as normal (SKILL.md); the visual notes become the graphics plan.
